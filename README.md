
# Changelog

All notable changes to the GreenLeaf Nursery Inventory Management System are documented in this file.

## [1.0.0] - 2026-11-03

### Added
- User authentication and login functionality.
- Role-based access control for Admin, Manager, and Employee.
- Centralized dashboard with inventory and sales summaries.
- Plant inventory management.
- Inventory search, filtering, and pagination.
- Plant category management.
- Sales transaction management.
- Sales analytics and date-range filtering where implemented.
- Staff user management and role assignment.
- Protected application routes.

### Improved
- Organized frontend architecture and Redux Toolkit state management.
- Improved authentication and authorization handling.
- Integrated frontend and backend REST APIs.
- Configured environment variables for deployment.
- Improved application maintainability.
- Added frontend testing configuration.

### Fixed
- API endpoint configuration issues.
- Frontend and backend integration issues.
- Authentication integration issues.
- CORS configuration issues encountered during deployment.
- Deployment configuration issues.

### Known Limitations
- Automated low-stock notifications.
- PDF and Excel report exports.
- Barcode-based inventory management.
- Advanced sales analytics.
- Automated database backup scheduling.
- Detailed audit logs.
- Expanded automated test coverage.
